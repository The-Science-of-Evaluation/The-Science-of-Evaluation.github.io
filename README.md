# The Science of Evaluation

This repository hosts the website for The Science of Evaluation, served with GitHub Pages at:

https://the-science-of-evaluation.github.io

Changes pushed to the `main` branch are published to the site automatically.

## Editing the site

- `index.html`: page content (overview, call for papers, dates, schedule, sponsor, contact).
- `data.js`: speakers and organizers (name, affiliation, role, photo, website).
- `styles.css` / `script.js`: styling, people cards, and the animated hero background.
- `assets/`: photos (`speakers/`, `organizers/`), the overview figure (`img/teaser.jpg`), and sponsor logos.
